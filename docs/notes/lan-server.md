# 局域网专用服务端

`mcgod` 是 M3B 的无渲染 TCP 专用服务端。启动一个新世界或打开已有世界：

```sh
mcgod --listen :25565 --world worlds/lan --seed 42
```

同一局域网中的客户端可连接服务器所在机器的私有地址：

```sh
mcgo --connect 192.168.x.x:25565 --name Chen
```

如果只允许本机连接，请明确监听 loopback 地址：

```sh
mcgod --listen 127.0.0.1:25565 --world worlds/local
```

按 `Ctrl-C`（SIGINT）或向进程发送 SIGTERM 可正常关闭服务端。它会停止接纳连接、刷写玩家和区块存档并释放 `world.lock`。备份前请先执行上述正常关服步骤，等待进程退出后再复制整个世界目录；不要在服务端运行时复制存档文件。

> 安全警告：M3B 没有认证，也没有加密。任何能连到监听地址的人都可尝试加入服务器。仅可用于可信局域网；不要在路由器上做端口映射，也不要暴露到公网。

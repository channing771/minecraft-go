# deterministic-ore-generation Specification

## Purpose

为煤矿与铁矿提供由世界种子与坐标决定、单点查询与整区块生成完全一致的确定性分布，使玩家可以稳定获取熔炼所需资源，同时不改写任何已保存区块。

## Requirements

### Requirement: 矿石分布只由世界种子与方块坐标决定
世界生成 SHALL 用世界种子与三维方块坐标的稳定哈希决定矿石，且不得依赖生成顺序、区块加载顺序、时间或任何可变状态。相同种子与相同坐标 MUST 始终得到相同方块；不同种子 MUST 在足够样本中至少产生一个不同结果。

#### Scenario: 相同种子重复生成结果一致
- **GIVEN** 固定世界种子
- **WHEN** 系统在不同时刻两次查询同一方块坐标
- **THEN** 两次结果 MUST 完全相同

#### Scenario: 不同种子产生不同分布
- **GIVEN** 两个不同的世界种子
- **WHEN** 系统在同一批固定坐标上查询矿石
- **THEN** 至少一个坐标的结果 MUST 不同

#### Scenario: 负坐标同样确定
- **GIVEN** 固定世界种子
- **WHEN** 系统查询 X 或 Z 为负数的方块坐标
- **THEN** 结果 MUST 稳定且与正坐标使用同一判断

### Requirement: 矿石只替换石头并遵守高度上限
矿石 SHALL 只替换本应生成为石头的方块，不得替换基岩、泥土、草或空气。煤矿 MUST 只出现在 `Y < 96`，铁矿 MUST 只出现在 `Y < 48`；同一坐标同时命中时 MUST 优先生成铁矿，使结果没有歧义。

#### Scenario: 非石头方块不被替换
- **GIVEN** 某坐标本应生成为基岩、泥土、草或空气
- **WHEN** 系统生成该坐标
- **THEN** 结果 MUST 保持原方块，不得变为矿石

#### Scenario: 超过高度上限不生成矿石
- **GIVEN** 某石头坐标满足 `Y >= 96`
- **WHEN** 系统生成该坐标
- **THEN** 结果 MUST 保持石头

#### Scenario: 铁矿判断优先于煤矿
- **GIVEN** 某石头坐标同时满足铁矿与煤矿的选中条件且 `Y < 48`
- **WHEN** 系统生成该坐标
- **THEN** 结果 MUST 是铁矿

### Requirement: 单点查询与整区块生成保持一致
系统 SHALL 让单点方块查询与整区块生成共用同一纯判断。对任意区块内的每个方块，单点查询结果 MUST 与整区块生成结果相同。

#### Scenario: 逐点比对整区块
- **GIVEN** 固定世界种子和任意区块位置
- **WHEN** 系统生成该区块并对其中每个方块单独查询
- **THEN** 每个位置的两种结果 MUST 相同

### Requirement: 矿石可挖掘并产出熔炼原料
煤矿和铁矿 SHALL 使用权威计时采掘规则：裸手或普通非工具物品需要 `30` tick 且完成后不产生矿物掉落，石镐需要 `15` tick、铁镐需要 `8` tick，并分别产生煤炭或粗铁。方块生成规则和已保存区块内容 MUST 不因工具门槛改变。

#### Scenario: 石镐挖掘煤矿得到煤炭
- **GIVEN** 玩家选中石镐并持续命中视线内的煤矿
- **WHEN** 权威进度达到 `15` tick
- **THEN** 系统 MUST 在原位置产生一个煤炭掉落物

#### Scenario: 石镐挖掘铁矿得到粗铁
- **GIVEN** 玩家选中石镐并持续命中视线内的铁矿
- **WHEN** 权威进度达到 `15` tick
- **THEN** 系统 MUST 在原位置产生一个粗铁掉落物

#### Scenario: 铁镐更快取得矿石
- **GIVEN** 玩家选中铁镐并持续命中煤矿或铁矿
- **WHEN** 权威进度达到 `8` tick
- **THEN** 系统 MUST 破坏目标并产生对应矿物掉落物

#### Scenario: 错误工具破坏矿石但不掉落
- **GIVEN** 玩家空手或选中普通非工具物品并持续命中煤矿或铁矿
- **WHEN** 权威进度达到 `30` tick
- **THEN** 系统 MUST 破坏目标但不得产生煤炭或粗铁掉落物

### Requirement: 已保存区块不因矿石规则改变而重写
新增矿石规则 MUST 只影响尚未生成的区块。系统 SHALL NOT 扫描、批量改写或重新生成任何已保存区块的方块内容。

#### Scenario: 旧区块内容保持不变
- **GIVEN** 世界目录中已存在使用旧规则生成并保存的区块
- **WHEN** 服务端用包含矿石规则的新版本加载该区块
- **THEN** 该区块的方块内容 MUST 与保存时完全相同

## MODIFIED Requirements

### Requirement: 快捷栏状态固定且有效
系统 SHALL 把完整权威物品状态的前 9 格作为快捷栏，并维护一个 `0..8` 的选中栏位；空栏位 MUST 同时具有空物品标识和零数量，非空栏位 MUST 具有已注册物品标识以及不超过该物品稳定单格上限的数量。石镐和铁镐的单格上限 MUST 为 `1`，其余当前物品的单格上限 MUST 为 `64`。

#### Scenario: 有效快捷栏可进入游戏
- **GIVEN** 完整物品状态的前 9 格有效且选中栏位在 `0..8`
- **WHEN** 服务端恢复或发布该状态
- **THEN** 系统接受快捷栏且不改变栏位顺序、物品或数量

#### Scenario: 越界或矛盾状态被拒绝
- **GIVEN** 快捷栏包含越界选中栏位、未知物品、空物品与非零数量、两个同格石镐或其他超过对应单格上限的数量
- **WHEN** 系统从网络或存档边界读取完整物品状态
- **THEN** 系统 MUST 拒绝整个状态且不得部分应用背包或其他快捷栏栏位

#### Scenario: 单个工具是有效快捷栏内容
- **GIVEN** 快捷栏某格包含数量为 `1` 的石镐或铁镐
- **WHEN** 服务端恢复或发布该状态
- **THEN** 系统 MUST 接受该栏位且不得要求该工具具有放置映射

### Requirement: 成功挖掘确定性获得资源
权威采掘完成且选中工具满足目标方块掉落等级时，系统 SHALL 在该方块中心创建或合并对应掉落物，并与方块修改在同一区块状态中原子提交；等级不足时方块 MAY 被破坏但不得产生方块掉落。采掘完成 MUST NOT 直接修改玩家快捷栏。系统 MUST 先合并同物品、同方块位置的最低稳定顺序未满堆，否则使用目标区块最低稳定顺序的空掉落物槽。

#### Scenario: 同位置同类物品优先合并
- **GIVEN** 目标泥土方块位置已有 63 个泥土物品的权威掉落物堆
- **WHEN** 玩家完成该泥土方块的权威采掘
- **THEN** 原堆数量变为 64、玩家快捷栏保持不变且目标方块变为空气

#### Scenario: 使用最低稳定顺序空槽
- **GIVEN** 目标区块没有可合并的同位置同类堆、至少两个掉落物槽为空且玩家使用可采集石头的手持状态
- **WHEN** 玩家完成一个石头方块的权威采掘
- **THEN** 最低稳定顺序的空槽获得一个石头掉落物、其他空槽和玩家快捷栏保持不变

#### Scenario: 石砖需要镐才能回收
- **GIVEN** 世界中有一个已放置石砖且目标区块能够接收掉落物
- **WHEN** 玩家分别用石镐和普通非工具物品完成采掘
- **THEN** 两种情况都把方块变为空气，但只有石镐情况创建或合并一个石砖掉落物

#### Scenario: 掉落物容量已满时不破坏可采集方块
- **GIVEN** 目标区块的 32 个掉落物槽都无法接收目标掉落物且玩家工具等级足够
- **WHEN** 玩家完成一个本可采集方块的权威采掘
- **THEN** 系统 MUST 返回稳定的容量拒绝，目标方块、区块掉落物和玩家快捷栏都保持不变

#### Scenario: 满栏不阻止生成掉落物
- **GIVEN** 玩家快捷栏没有空间且目标区块能够接收目标掉落物
- **WHEN** 玩家使用足够等级工具完成一个可采集方块的权威采掘
- **THEN** 目标方块变为空气、对应掉落物被创建或合并且快捷栏保持不变

#### Scenario: 被保护方块不产生资源
- **GIVEN** 目标方块受保护或没有注册采掘规则
- **WHEN** 玩家持续尝试采掘该方块
- **THEN** 系统 MUST 保持采掘进度清零且不得修改方块、掉落物或快捷栏

### Requirement: 协议升级保持有界和可判定
线上协议 SHALL 升级为 v8，并对持续采掘输入、权威采掘状态、选择栏位、放置栏位、整堆移动、合成、完整物品状态以及掉落物消息执行严格长度、批次、顺序、枚举和数值校验；v7 或其他不匹配版本 MUST 在登录前稳定拒绝，不提供版本协商或降级解码。废止的即时破坏 packet ID `1` MUST 保留未分配且不得被其他消息复用。

#### Scenario: v8 消息可确定性往返
- **GIVEN** 任一有效的持续输入、权威采掘状态、选择、放置、整堆移动、合成、完整物品状态或掉落物消息
- **WHEN** 消息经过 v8 编码再解码
- **THEN** 解码结果与原值相同且编码字节稳定

#### Scenario: 非法负载被拒绝
- **GIVEN** 物品、合成、采掘或掉落物消息包含截断、尾随字节、未知物品、未知配方、非法数量、越界栏位或位置、矛盾进度、重复 ID、乱序 ID 或超限批次
- **WHEN** v8 解码器处理该消息
- **THEN** 解码器 MUST 返回错误且不得 panic、分配无界内存或输出部分消息

#### Scenario: 废止 packet ID 不复用
- **GIVEN** 已进入 Play 的 v8 对端发送 packet ID `1`
- **WHEN** 解码器处理该帧
- **THEN** 系统 MUST 将其视为协议违规且不得把它解释为任何其他命令

#### Scenario: v7 客户端被拒绝
- **GIVEN** 客户端在握手中声明协议 v7
- **WHEN** 它连接 v8 服务端
- **THEN** 服务端在进入 Play 前返回稳定的不兼容版本结果并关闭登录流

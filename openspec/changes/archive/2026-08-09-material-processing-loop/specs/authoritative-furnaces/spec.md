## MODIFIED Requirements

### Requirement: 熔炼只在活动范围内按固定节奏推进
熔炉 SHALL 只在至少一名 Ready 玩家处于同一维度且区块半径 2 的活动范围内推进。系统 MUST 按稳定的维度、区块坐标与槽位顺序处理，使多名玩家的重叠观察在同一 tick 内只推进一次。固定熔炼映射 MUST 为粗铁到铁锭、沙子到玻璃、黏土块到砖块；任一映射的熔炼进度满 200 tick MUST 产出一个对应产物，燃料每次点燃 MUST 消耗一个煤炭并设置 1600 个燃烧 tick。

#### Scenario: 粗铁燃料点燃并开始推进
- **GIVEN** 某活动熔炉输入格有粗铁、燃料格有煤炭、输出格可接收铁锭且剩余燃烧 tick 为 0
- **WHEN** 系统推进该熔炉一个 tick
- **THEN** 系统 MUST 消耗一个煤炭、把剩余燃烧 tick 设为 1600 后再减少一个，并把熔炼进度增加到 1

#### Scenario: 沙子完成后产出玻璃
- **GIVEN** 某活动熔炉的输入格有沙子、输出格可接收玻璃且熔炼进度为 199
- **WHEN** 系统推进该熔炉一个 tick
- **THEN** 系统 MUST 消耗一个沙子、向输出格加入一个玻璃并把进度归零

#### Scenario: 黏土块完成后产出砖块
- **GIVEN** 某活动熔炉的输入格有黏土块、输出格可接收砖块且熔炼进度为 199
- **WHEN** 系统推进该熔炉一个 tick
- **THEN** 系统 MUST 消耗一个黏土块、向输出格加入一个砖块并把进度归零

#### Scenario: 一个煤炭恰好支持八个熔炼产物
- **GIVEN** 某活动熔炉只有一个煤炭、足量任一已注册熔炼输入且输出容量充足
- **WHEN** 系统持续推进直到燃烧 tick 耗尽
- **THEN** 该熔炉 MUST 恰好产出 8 个与输入对应的产物

#### Scenario: 多人重叠观察不重复推进
- **GIVEN** 八名 Ready 玩家的活动范围都覆盖同一个熔炉
- **WHEN** 系统推进一个 tick
- **THEN** 该熔炉的进度与燃烧 tick MUST 各自只变化一次

#### Scenario: 离开活动范围后暂停
- **GIVEN** 某熔炉正在推进
- **WHEN** 所有 Ready 玩家都离开该熔炉的活动范围
- **THEN** 系统 MUST 停止推进该熔炉，且进度与剩余燃烧 tick MUST 保持不变

### Requirement: 条件无效时熔炼完全暂停且不浪费燃料
输入格不含任一已注册熔炼输入，或输出格无法再接收当前输入对应的产物时，系统 MUST 同时停止增加熔炼进度和减少剩余燃烧 tick。条件恢复后 MUST 从原值继续，使燃料不会在空转中静默损失。

#### Scenario: 输入为空时冻结
- **GIVEN** 某熔炉有剩余燃烧 tick 与非零熔炼进度，但输入格为空
- **WHEN** 系统推进一个 tick
- **THEN** 熔炼进度与剩余燃烧 tick MUST 都保持不变

#### Scenario: 输出已满时冻结
- **GIVEN** 某熔炉输入格有粗铁且有剩余燃烧 tick，但输出格已达单格上限
- **WHEN** 系统推进一个 tick
- **THEN** 熔炼进度与剩余燃烧 tick MUST 都保持不变

#### Scenario: 输出与当前输入的产物冲突时冻结
- **GIVEN** 某熔炉输入格有沙子、输出格有铁锭、熔炉有非零进度与剩余燃烧 tick
- **WHEN** 系统推进一个 tick
- **THEN** 进度、剩余燃烧 tick 和三个栏位的物品 MUST 全部保持不变

#### Scenario: 条件恢复后从原值继续
- **GIVEN** 某熔炉因输出已满而暂停，其进度为 137、剩余燃烧 tick 为 1463
- **WHEN** 玩家取出输出物品后系统推进一个 tick
- **THEN** 进度 MUST 变为 138 且剩余燃烧 tick MUST 变为 1462

### Requirement: 熔炉界面使用统一栏位并按容器约束校验
熔炉界面 SHALL 使用统一栏位 `0..38`，其中 `0..35` 是玩家物品栏，36 是输入格，37 是燃料格，38 是输出格。输入格 MUST 只接受任一已注册熔炼输入，燃料格 MUST 只接受煤炭，输出格 MUST 只能作为来源而不能作为目标。

#### Scenario: 输入格接受已注册熔炼输入
- **GIVEN** 玩家已打开某熔炉且物品栏中有沙子或黏土块
- **WHEN** 玩家请求把该物品移动到输入格
- **THEN** 系统 MUST 在其他栏位约束也满足时接受该移动

#### Scenario: 输入格拒绝非熔炼输入
- **GIVEN** 玩家已打开某熔炉且物品栏中有煤炭
- **WHEN** 玩家请求把煤炭移动到输入格
- **THEN** 系统 MUST 稳定拒绝，且玩家物品与熔炉状态 MUST 保持不变

#### Scenario: 输出格不能作为目标
- **GIVEN** 玩家已打开某熔炉且物品栏中有铁锭
- **WHEN** 玩家请求把铁锭移动到输出格
- **THEN** 系统 MUST 稳定拒绝，且玩家物品与熔炉状态 MUST 保持不变

#### Scenario: 从输出格取出熔炼产物
- **GIVEN** 玩家已打开某熔炉，输出格有任一已注册熔炼产物且玩家物品栏有空间
- **WHEN** 玩家请求把输出格整堆移动到物品栏
- **THEN** 系统 MUST 同时更新玩家物品与熔炉输出格，并向该玩家确认新的完整物品状态

## ADDED Requirements

### Requirement: 输入种类切换清零熔炼进度但保留燃烧时间
一次权威栏位移动若使输入格的物品种类改变，系统 MUST 把 `ProgressTicks` 清零并保留 `BurnTicks`；移除后放回同种输入也 MUST 依据最终权威输入状态重新开始，不得转移或额外获得进度。

#### Scenario: 切换输入种类清零进度
- **GIVEN** 某熔炉输入格有粗铁、`ProgressTicks` 为 137 且 `BurnTicks` 为 1463
- **WHEN** 一次权威栏位移动把输入格改为沙子
- **THEN** `ProgressTicks` MUST 变为 0，`BurnTicks` MUST 保持 1463，且栏位移动之外的物品保持不变

#### Scenario: 移除并放回同种输入不保留进度
- **GIVEN** 某熔炉输入格有沙子且 `ProgressTicks` 为 137
- **WHEN** 权威栏位移动先移除沙子再把沙子放回输入格
- **THEN** 最终输入格为沙子时 `ProgressTicks` MUST 为 0

## MODIFIED Requirements

### Requirement: 图形客户端提供固定背包界面
图形客户端 SHALL 使用 `E` 打开或关闭包含 27 格背包、9 格快捷栏以及石砖、熔炉和铁块三条固定配方入口的界面，并以两次左键点击依次选择来源和目标。每条配方入口 MUST 从最后确认的完整物品镜像显示原料、产物及自身当前可合成状态。打开熔炉时，同一界面 MUST 改为显示统一栏位 `0..38`，即 36 格玩家物品加输入、燃料、输出三格以及权威燃烧与熔炼进度，并复用同一渲染 pipeline 与固定容量缓冲。界面打开时 SHALL 释放鼠标并抑制移动、视角、挖掘、放置和数字键选择输入；世界和服务端 tick MUST 继续运行。关闭、断开、重新登录、维度 reset 或收到熔炉关闭通知 MUST 清除尚未提交的本地选择。

#### Scenario: 三条固定配方同时显示
- **GIVEN** 背包界面已打开且没有打开熔炉
- **WHEN** 客户端绘制最后确认的完整物品镜像
- **THEN** 界面同时显示 `4 石头 → 4 石砖`、`8 石头 → 1 熔炉`和 `9 铁锭 → 1 铁块`以及各自独立的可合成状态

#### Scenario: 两次点击发送一次移动请求
- **GIVEN** 背包界面已打开且没有已选来源
- **WHEN** 玩家依次左键点击两个有效栏位
- **THEN** 客户端只发送一个引用这两个栏位的移动请求且不本地改写物品数量

#### Scenario: 点击任一可用配方发送一次合成请求
- **GIVEN** 背包界面已打开且最后确认镜像显示三条固定配方中的任意一条可合成
- **WHEN** 玩家左键点击该配方入口一次
- **THEN** 客户端只发送一个引用该配方稳定 recipe ID 的合成请求且不本地扣除原料或增加产物

#### Scenario: 不可用配方不发送请求
- **GIVEN** 最后确认镜像显示某条固定配方原料不足或产物无容量
- **WHEN** 玩家点击该配方入口
- **THEN** 客户端不得发送合成请求且完整物品镜像保持不变

#### Scenario: 右键熔炉发送打开请求
- **GIVEN** 玩家视线内六格范围有熔炉方块
- **WHEN** 玩家按下放置键
- **THEN** 客户端只发送一个打开熔炉请求，不发送放置请求，也不本地打开界面

#### Scenario: 收到权威状态后才显示熔炉
- **GIVEN** 客户端已发送打开熔炉请求
- **WHEN** 客户端收到服务端的完整熔炉状态
- **THEN** 客户端才显示三格内容与进度，并且在此之前不得显示预测值

#### Scenario: 熔炉界面两次点击发送一次跨容器移动
- **GIVEN** 熔炉界面已打开且没有已选来源
- **WHEN** 玩家依次左键点击统一栏位 `0..38` 中的两个有效位置
- **THEN** 客户端只发送一个引用完整熔炉引用与这两个索引的移动请求，且不本地改写任何一侧

#### Scenario: 打开界面抑制游戏输入
- **GIVEN** 背包界面已打开
- **WHEN** 玩家移动鼠标、按移动键、数字键或点击鼠标按钮
- **THEN** 客户端只处理界面点击，不发送移动、视角、挖掘、放置或快捷栏选择请求

#### Scenario: 关闭界面恢复捕获
- **GIVEN** 背包界面已打开且已选择一个来源栏位
- **WHEN** 玩家按 `E` 或 `Escape` 关闭界面
- **THEN** 本地来源选择被清除，鼠标重新捕获且后续游戏输入恢复

#### Scenario: 服务端关闭通知清除界面
- **GIVEN** 熔炉界面已打开且已选择一个来源
- **WHEN** 客户端收到熔炉关闭通知、断开连接或玩家状态 reset
- **THEN** 客户端 MUST 关闭熔炉界面并清除本地来源选择

#### Scenario: 自动验证不打开窗口
- **GIVEN** CI 或开发者运行背包、合成或熔炉的协议、模拟、存档、客户端或渲染测试
- **WHEN** 自动验证执行
- **THEN** 测试 MUST 可在不启动或聚焦交互式游戏窗口的情况下完成
